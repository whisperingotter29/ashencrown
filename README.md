# Ashen Crown

Top-down pixel-art action RPG that runs in the browser.

- `npm install` then `npm run dev` to play locally (http://localhost:5173)
- `npm run build` builds the static site into `dist/` (what Vercel serves)
- `npm run build:single` builds one self-contained page in `dist-single/`
- `desktop/` is the downloadable app (Windows, macOS, Linux / Steam Deck) and the Steam setup:
  see `desktop/README.md`

Design and pass notes: `PIXEL_PASS_NOTES.md`.
